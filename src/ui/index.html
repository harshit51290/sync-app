    Browsers cannot watch your gallery in the background. Install the tiny PhoneSync client once and every new photo is pushed as it appears — even while the screen is off.

    Install Termux, then run
    pkg install rust termux-api
    Copy the client onto the phone (built on the laptop)
    Start the watcher — it finds this laptop by itself
    phonesync send /sdcard/DCIM --watch
