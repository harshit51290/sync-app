How a phone connects

Both devices must be on the same Wi-Fi. Open the phone camera and scan the code on the Overview tab — the token travels inside the link, so nobody else on the network can upload.

For hands-free background sync, install the PhoneSync app on the phone and pair it with this laptop once. It then watches the camera roll and sends anything new whenever both are on the same Wi-Fi.
